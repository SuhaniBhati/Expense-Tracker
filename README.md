Expense Tracker

A full-stack expense management application designed to help users record, organize, monitor, and analyze their personal expenses through a clean and intuitive interface.

The application provides a centralized dashboard for tracking financial activity, managing expense records, and gaining insights into spending patterns.

Session/token-based authorization
💰 Expense Management

Track expense dates
📊 Dashboard & Analytics
Overview of total expenses
